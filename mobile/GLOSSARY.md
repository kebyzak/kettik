# kettik · глоссарий

| В коде | Игрок видит | Что это |
|---|---|---|
| `Game` | игра | Комната и бронь поля вместе: состав, время, аренда. На сервере это `Room` + `Booking`. |
| `Place` | место, №14 | Одно место в составе. Номер — позиция в `Game.places` плюс один. |
| `FreePlace` | свободно, «занять» | Место, которое никто не держит. |
| `HeldPlace` | держит место, `04:12` | Место занято и ждёт оплаты. Держится 10 минут, но не дольше дедлайна сбора. На сервере `RESERVED`. |
| `PaidPlace` | оплатил | Оплата зачтена. На сервере `PAID`. |
| `GameStatus.funding` | Идёт сбор · до 20:30 | Бронь удерживает слот, пока собирают деньги. На сервере `HELD`. |
| `GameStatus.confirmed` | Игра состоится | Все места оплачены, бронь подтверждена. `CONFIRMED`. |
| `GameStatus.expired` | Не собрались — вернём деньги | Дедлайн наступил при недоборе, всем возврат. `EXPIRED`. |
| `GameStatus.cancelled` | Отменена — вернём деньги | Отменил организатор или площадка. `CANCELLED`. |
| `deadline` | сбор до … | Раньшее из: создание + 24 ч, начало − 2 ч. |
| `shareOf(n)` | ваша доля | Аренда, делённая на места. Остаток по 1 ₸ на первые места. |
| `Tenge` | ₸ | Целые тенге. API хранит минимальные единицы и переводит на границе. |
| pitch / `PitchView` | поле | Изометрическое поле из логотипа. Только на экранах одной игры. |
| `DotStrip` | точки | Одна точка на место. В списках вместо поля. |

Слова для игрока задаются в `lib/ui/words.dart`, и только там.
